      2 ## __Directives__ ##
      3 
      4 A .basm input file is made of directives starting with the % character. Some directive starts a block that ends with the respective %end directive. Others are  single line directives. The table below lists the directives that can be used in a .basm file.
      5 
      6 | Directive     | End directive  | Description  |
      7 | -------------:|:-------------| :-----|
      8 | %section      | %endsection | Code section |
      9 | %macro        | %endmacro |  Macro definition|
     10 | %fragment     | %endfragment | Code fragment |
     11 | %chunk        | %endchunk | Chunk of data |
     12 | %meta bmdef   | none | BondMachine metadatas |
     13 | %meta cpdef   | none | CP metadatas |
     14 | %meta sodef   | none | SO metadatas |
     15 | %meta iodef   | none | Input/Output metadatas |
     16 | %meta fidef   | none | Fragment Instance metadata |
     17 | %meta filinkdef   | none | Fragment Instance Link metadatas |
     18 | %meta soatt   | none | SO attach directives |
     19 | %meta ioatt   | none | IO attach directives |
     20 | %meta filinkatt   | none | Fragment Instance link attach directives |

     22 ## __Sections__ ##
     23 
     24 The main Basm structure is the section. A section is a block of code or data.
     25 The directive %section is used start a section  and ends with the directive %endsection. The syntax is:
     26 
     27     %section section_name section_type [section metadata]
     28     ...
     29     %endsection
     30 
     31 Within Basm four type of sections can be defined:
     32 
     33 - __romtext__: Read only code section
     34 - __romdata__: Read only data section
     35 - __ramtext__: Code section
     36 - __ramdata__: Data section
     37 
     38 The section name is a valid identifier. It has to be unique in the current BasmInstance. The section type is one of the four listed above. The section metadata is a list of metadata that are associated to the section. The metadata are used to define the section properties. The list of metadata is given in the table below.
     39 
     40 | Metadata     | Description  |
     41 | -------------:|:-------------|
     42 | __iomode__ | The defualt I/O mode for the section. It can be __sync__ or __async__. The default is __async__. |
