      3 **Instruction**: inc
      4 
      5 **Length**: opBits + regBits
      6 
      7 **Description**:
      8 
      9 The INC instruction increments a register by 1. It assumes that the register is a positive integer and it will overflow to 0 if the maximum value is reached. The length of the register is defined by the architecture.

     15 %section code .romtext  ; The section name is code and it is a ROM program
     16         entry _start    ; Entry point
     17 _start:
     18 
     19         clr     r0      ; Clear register r0
     20 loop:
     21         inc	r0      ; Increment register r0
     22 	r2o	r0,o0   ; Output register r0 to the special output register o0
     23         j	loop    ; Jump to loop

     25 %endsection

     28 %meta ioatt     testio cp: cpu, index:0, type:output    ; Define an output bond to the CP (outgoing, CP endpoint)
     29 %meta ioatt     testio cp: bm, index:0, type:output     ; Define an output bond to the BM (outgoing, BM endpoint)
     30 %meta bmdef	global registersize:8                   ; Define the register size of the BM to 8 bits
     31 ```
